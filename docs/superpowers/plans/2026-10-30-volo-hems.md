# Volo e operazioni speciali – piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** registrare tempo di volo, tipo di missione e manovre delle missioni V-ECHO e T-ECHO, con avvisi, backup v2, vista "Volo" nelle statistiche identica alle tabelle di volo dell'Excel HEMS, colonne VOLO nell'export e uno script che importa i voli già registrati.

**Architecture:** tre campi nuovi nel record (`tipoMissione`, `tempoVolo`, `manovre`) gestiti dalla logica pura in `js/core/` (campi, modulo, controlli, merge, excel) e da un modulo nuovo `js/core/volo.js` per le statistiche. La UI aggiunge la sezione "Volo" al form e una vista "Volo" (`js/ui/volo.js`) alle statistiche. Due strumenti Python solo libreria standard: `tools/hems_to_json.py` (import) e `tools/attese_volo.py` (valori attesi per il confronto con l'Excel).

**Tech Stack:** HTML, CSS, JavaScript vanilla (ES modules), Chart.js 4.5.1 e SheetJS CE 0.20.3 già in `vendor/`, test `node --test`, prove end-to-end con Playwright installato sul computer, Python 3 (stdlib).

**Spec:** `docs/superpowers/specs/2026-10-30-volo-hems-design.md`

## Global Constraints

- Nessuna dipendenza nuova, nessun build step, nessuna chiamata di rete; gli strumenti Python usano solo la libreria standard.
- Interfaccia e messaggi in italiano; nomi di variabili e funzioni in italiano, come il codice esistente.
- Elicotteri: `MEZZI_ELICOTTERO = ['V-ECHO', 'T-ECHO']`. Manovre, in quest'ordine: HD, VD, HS, VS, VSP, VSB.
- Lista `tipoMissione`: HEMS, HSR, IFT, nessuna voce di sistema.
- Tempo di volo valido: intero da 0 a 600 minuti.
- Formato del backup: versione 2; si leggono 1 e 2.
- I file `.xlsx` originali non si modificano mai. I dati reali stanno solo in `data/` (escluso da git): test, fixture e screenshot usano solo dati inventati (codici missione `99ZZ....`).
- Commit solo in locale, sul branch `volo-hems`. Nessun push senza l'ok esplicito dell'utente.
